# Weather App 🌦️

This is a simple weather application that fetches real-time weather data using the [WeatherAPI](https://www.weatherapi.com/).

## Features
- Search for any location
- Displays temperature in °C
- Shows weather conditions and local time

## Technologies Used
- HTML
- CSS
- JavaScript (Vanilla)
- WeatherAPI

## Setup Instructions
1. Clone the repository
2. Open `index.html` in your browser
3. Make sure to replace the API key in `script.js` with your own from WeatherAPI
